# Аналитика: каналы, экономика РФ и Ленобласти

Публичная версия дашборда по Telegram @lenoblinvest, MAX «Экономика Ленобласти», ВКонтакте, экономике России и Ленинградской области.

Сайт — это одна страница `index.html`, её показывает GitHub Pages.

## Как устроено

- `data/*.json` — данные, по файлу на каждый блок дашборда.
- `build/page_body.html`, `build/page_scripts.js` — разметка и код страницы.
- `build/build.py` — собирает `index.html` из шаблона и всех файлов в `data/` (список — в `build/datasets.txt`).
- `d3.min.js` — библиотека графиков, лежит рядом, чтобы страница не зависела от внешних CDN.

## Обновление

Ежечасное запланированное задание Claude собирает свежие данные, записывает изменённые файлы в `data/`, запускает

```
python3 build/build.py
```

и отправляет изменения в этот репозиторий. GitHub Pages публикует новую версию за 1–2 минуты.

## Свой домен

Чтобы сайт открывался, например, по адресу `dashboard.lenoblinvest.ru`, в DNS домена нужна запись
`CNAME dashboard → ssm-dot1.github.io`, а в корне репозитория — файл `CNAME` с этим адресом.
